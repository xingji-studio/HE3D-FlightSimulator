# HE3D Examples

[中文版](examples.md)

- `TriangleTest`: minimal value-`Mesh` rendering.
- `AirplaneTest`: OBJ loading and anti-aliasing toggles.
- `PhysicsTest`: `PhysicsProperties`, `BoxCollider`, `MeshCollider`, and scene-owned runtime state.
- `FlightSimulator`: dynamic terrain mesh values, refreshed `MeshCollider` caches, and scene physics.
